## Arquivos
- index.html: página, estilos e interações.
- assets/: imagens e fontes locais (Manrope, licença em assets/LICENSE-Manrope.txt).
- robots.txt e sitemap.xml: indexação nos buscadores.
- vercel.json: configuração de publicação.

## Publicação
O projeto está ligado à Vercel (Framework Preset: Other, sem Build Command). Cada push no branch principal publica o site automaticamente. Para abrir localmente, basta abrir index.html com a pasta assets ao lado.

## Recursos
Introdução com logo, cabeçalho e navegação lateral, movimento associado à rolagem nativa, menu mobile, galeria ampliada com controles e gesto lateral, acordeões, WhatsApp com mensagens contextuais, links diretos para o Instagram, endereço/rota, privacidade, dados estruturados (RealEstateAgent) e prévia de compartilhamento.
